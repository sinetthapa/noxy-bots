## parts

Each part has a few variants. Mix them however you like.

| Part | Variants | Default |
| --- | --- | --- |
| `body` | `nox`, `box` | `nox` |
| `ears` | `nox`, `antenna`, `none` | `nox` |
| `eyes` | `capsule`, `round` | `capsule` |
| `bolts` | `nox`, `none` | `nox` |

<Demo attrs="body=box ears=antenna eyes=round" />

## sizes

Four sizes, each from 0.7 to 1.3, default 1. In React and JS they live in `look.sizes`.

| Attribute | In `look.sizes` |
| --- | --- |
| `eye-size` | `eye` |
| `eye-spacing` | `eyeSpacing` |
| `ear-size` | `ear` |
| `bolt-size` | `bolt` |
